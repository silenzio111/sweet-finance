Personal finance, kept personal

把钱花在哪，
一眼就清楚。

一个以手机体验为中心的本地记账本。收入、支出、储蓄和年度目标各得其所，不把你的账本变成一张无尽的表格。

查看源代码了解功能

为持续记录而做，而非只做一次报表。

SweetFinance 把常用动作收进清爽的移动界面，同时保留分类、年度、历史记录与备份这些真正长期需要的能力。

全年一张账本

按年份维护收入、支出和储蓄项目，随时切换视图查看当下或回顾全年。

账目也能合你习惯

自定义分类、项目与卡片排序；精简模式和明细模式各自服务不同的查看场景。

改错也安心

调整历史、撤销/重做和明确的操作确认，减少误操作带来的焦虑。

本地优先

数据默认留在设备上；只有你主动执行时才会导入、导出或创建备份。

看得懂的指标

自动汇总净结余、储蓄率、支出占比和分类统计，也支持汇率管理。

Web 到 Android

React/Vite Web 应用配合 Capacitor Android 封装，方便在不同设备上继续迭代。

自己的数据，自己带走。

导出的备份由你保管，恢复也由你发起。没有账户体系，没有广告追踪，也没有把日常消费记录交给云端的必要。
